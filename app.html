Google Ads API application

Ads Performance Reporting

An internal reporting tool that consolidates Google Ads performance data into daily spreadsheet reports for the advertising accounts its operator manages.

What it does

The tool runs on a schedule and writes marketing performance data into a Google Sheets report used to track advertising results:

  • Daily campaign metrics — cost, impressions, clicks and conversions, broken down by day and by campaign.
  • Call tracking — calls generated by call assets, including missed ones, so that a missed enquiry can be followed up the same day.
  • Cross-channel reporting — the Google Ads figures are placed next to data from other marketing channels and the client's booking records, to calculate cost per lead and cost per booking.

Why the API is required

Part of this reporting currently runs on Google Ads Scripts. That environment does not expose Smart campaigns: a report over the campaign resource returns every other campaign type but omits Smart campaigns entirely, and a query filtered on advertising_channel_type = 'SMART' returns no rows at all.

As a result the spreadsheet under-reports total spend, which makes cost per lead wrong. The Google Ads API returns the complete picture, which is the reason for this application.

Data it accesses

The application requests a single OAuth scope, https://www.googleapis.com/auth/adwords, and uses it to read advertising statistics only from the Google Ads accounts that the authorising user already has access to.

It does not create, modify or pause campaigns, does not change budgets or bids, and does not access personal data of end users or any payment information. Full detail is in the privacy policy.
