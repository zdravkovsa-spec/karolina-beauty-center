Ads Performance Reporting

Privacy Policy

Last updated: 3 August 2026

Who this covers

This policy describes how the application Ads Performance Reporting ("the application") handles data obtained through Google APIs. The application is operated by Sergey Zdravkov, an independent Google Ads specialist based in Bucharest, Romania (zdravkov.s.a@gmail.com).

The application is an internal tool. It is not publicly distributed, has no registration, and is used solely by its operator for the advertising accounts under his management.

What data the application accesses

The application requests one OAuth scope: https://www.googleapis.com/auth/adwords.

Using it, the application reads advertising performance statistics only from Google Ads accounts the authorising user already has access to:

  • campaign names, identifiers and types;
  • daily metrics: cost, impressions, clicks, conversions;
  • call reporting for calls generated by ads: time, duration, status, and the caller's country and area code.

Note on phone numbers: Google itself withholds the caller's number for missed calls. Where a number is returned for an answered call, it is used only to match the call against the advertiser's own booking records, and is not disclosed to anyone else.

What the application does not do

  • It does not create, edit, pause or delete campaigns, ads, budgets or bids.
  • It does not access billing or payment information.
  • It does not access Gmail, Drive documents, contacts, calendars or any Google service other than Google Ads.
  • It does not collect personal data of the advertiser's website visitors.
  • It does not use data for advertising, profiling or training AI models.
  • It does not sell, rent or transfer data to third parties.

How data is used and stored

Retrieved statistics are written into a private Google Sheets report owned by the operator, and are used exclusively to produce marketing reports for the advertiser whose account the data came from. Access to that spreadsheet is limited to the operator and the advertiser.

OAuth credentials (client secret and refresh token) are stored locally on the operator's machine with file permissions restricted to the owner, and are excluded from version control. They are never shared.

Data is retained for as long as the reporting relationship with the advertiser continues, and is deleted on request or when that relationship ends.

Limited Use disclosure

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access granted to the application can be withdrawn at any time at myaccount.google.com/permissions. Once revoked, the application can no longer read any data.

To request deletion of data already collected, write to zdravkov.s.a@gmail.com.

Changes

If this policy changes, the revised version will be published on this page with an updated date.
